🚗 Hybrid Brake Disc QC with ECA & Dual-Stream AI
🎯 Overview
Industrial-grade Quality Control (QC) for automotive brake discs. This system uses a Hybrid Dual-Stream Architecture (CNN + Transformer) with Efficient Channel Attention (ECA) to localize micro-cracks and assess structural integrity.
🚀 Key Features
• Dual-Stream: MobileNetV2 (Local details) + ViT-Small (Global context).
• ECA Attention: Adaptive channel recalibration for sharper defect signals.
• Explainable AI: Grad-CAM heatmaps for decision transparency.
• Safety-First: Smart Threshold (\tau=0.25) to catch high-risk casting faults.
• Dashboard: Streamlit UI with automated audit logging.
